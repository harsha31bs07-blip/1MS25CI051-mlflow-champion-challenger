# Dataset provenance

The 60 evaluation sentences (30 positive, 30 negative) and eight new examples
were authored for this assignment with AI assistance. Labels are intended human
sentiment judgments, not labels produced by either candidate model. IDs preserve
order. There is no training stage. The new examples are disjoint from evaluation.
This small convenience set tests the workflow; it cannot estimate general benchmark
performance or establish statistical significance. Negation, mixed sentiment and
sarcasm are deliberately included. No sentence was edited in response to predictions.
